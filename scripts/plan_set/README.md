# סט תוכניות לבדיקת קריאת התוכנית

תוכניות דירה אמיתיות, בשני סגנונות שרטוט (קירות אפורים, קירות כהים), שעליהן
מודדים את חילוץ הקירות מהפיקסלים לסיור התלת-ממדי. הפרטים: `docs/plan-3d-tour.md`.

```sh
for f in scripts/plan_set/*.jpg; do
  python3 scripts/plan_cv_walls.py "$f" && python3 scripts/plan_cv_filter.py "$f" && python3 scripts/plan_cv_rooms.py "$f"
done
```

הפלט (JSON ותמונת בדיקה לכל תוכנית) נכתב ל-`/tmp/plan_cv`, או ל-`PLAN_OUT`.
זה אב-טיפוס: אותם ספים לכל התוכניות, בלי כיוונון לתוכנית בודדת. תוכנית חדשה
נוספת לכאן כקובץ, ואם היא נשברת מתקנים את הכלל ולא את הסף שלה.
