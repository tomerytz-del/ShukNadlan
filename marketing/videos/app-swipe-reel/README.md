# רילס ההחלקה: "מחפשים דירה כמו שגוללים בטלפון?"

רילס של כ-25 שניות לגולשים, לקמפיין ההחלקה (טיזר 8-14.11.2026, השקה 15.11,
דף `/swipe`). נוסחה 3 מ-`docs/reels-playbook.md` (בסגנון ChikChak), חתוך
**מהקלטות מסך אמיתיות** של האתר בטלפון (6.11.2026). לא Reelkit: החיתוך,
ההאצות, הכתוביות ודף הסיום נעשים ב-ffmpeg ו-PIL ב-`build_reel.py`.

הסיפור: בעיה (מחפשים בעשרה מקומות) ← גילוי (הכול בחיפוש אחד, מחליקים) ← פתרון (שומרים,
גבריאלה מתאמת ביקור, הדמיית AI, מחשבון) ← CTA (הקישור בביו).

## בנייה

ההקלטות, הגופן וההקלטה הקולית אינם בריפו (אין קבצים בינאריים בגיט).

```sh
REEL_SRC=~/reel-src REEL_FONT=~/fonts/Heebo-Bold.ttf \
  python3 build_reel.py out.mp4            # בלי קול (טיזר עם מוזיקה מהאפליקציה)
REEL_SRC=~/reel-src REEL_FONT=~/fonts/Heebo-Bold.ttf \
  python3 build_reel.py out.mp4 vo.wav     # עם הקריינות כפסקול
```

`REEL_SRC` הוא תיקייה עם ארבעת קובצי ההקלטה בשמותיהם המקוריים (`C1`..`C4` בראש
הסקריפט). ‏Heebo Bold מורידים מ-fonts.gstatic.com (הקישור בתוך ה-CSS של
fonts.googleapis.com); בלעדיו הסקריפט נופל ל-DejaVu Sans Bold.

הסקריפט כותב `timeline.json` ליד הפלט: תחילת וסוף כל שורה בשניות, לסנכרון
הקריינות. **35% התחתונים נקיים מטקסט** בכל פריים, והסקריפט בודק זאת (`TEXT_FLOOR`).
