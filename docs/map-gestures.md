# מחוות מגע במפה — יציאה ממלכודת הגלילה

מפה שתופסת חצי מסך במובייל בולעת את הגלילה: אצבע שנוחתת עליה בדרך למטה מזיזה
את המפה במקום להמשיך במורד הדף. בדף הבית, שבו המפה היא כמעט מסך שלם ומיד
מתחתיה התוצאות, זו הייתה חומה — מי שגלל/ה עם האגודל במרכז המסך פשוט לא הגיע/ה
לרשימה.

הפתרון הוא **מחוות משתפות פעולה** (cooperative gestures), אותו דפוס שגוגל מפות
מפעילה במפות מוטמעות:

| מחווה | מה קורה |
|---|---|
| אצבע אחת | הדף נגלל כרגיל — המפה מתנהגת כמו תמונה |
| שתי אצבעות | הזזה, קירוב וריחוק של המפה עצמה |
| ניסיון גרירה באצבע אחת | בועית: **"מזיזים את המפה בשתי אצבעות"**, נעלמת לבד |
| נגיעה / לחיצה על פין | ללא שינוי — נפתח הבלון, נפתח הנכס |

## איך זה עובד

`assets/map-gestures.js`, קובץ משותף בלי תלויות (כמו `quality-badge.js`):

```js
MapGestures.apply(map);                  // בועית ברירת המחדל
MapGestures.apply(map, { text:'…' });    // נוסח משלכם
```

הליבה היא **שורה אחת** — `map.dragging.disable()` — ולא שכתוב של מנגנון המגע.
זה עובד כי Leaflet עצמו קובע את `touch-action` לפי ה-handlers הפעילים:

| מחלקה שמוסיף Leaflet | `touch-action` | כלומר |
|---|---|---|
| `.leaflet-touch-drag` (handler הגרירה) | `none` | הדפדפן לא גולל — זו המלכודת |
| `.leaflet-touch-zoom` (handler הזום) | `pan-x pan-y` | הדפדפן כן גולל |

כיבוי הגרירה בלבד משאיר את הצירוף הרצוי: הדפדפן גולל באצבע אחת, ו-`touchZoom`
של Leaflet — שמזיז את המפה לפי מרכז שתי האצבעות וגם מקרב — עובד בשתיים.

**למה לא הפלאגין `leaflet-gesture-handling`:** הוא היה עוד תלות CDN לדף שכבר
תלוי בשלוש, עם טקסט ברירת מחדל באנגלית ועם שינוי נלווה להתנהגות הגלגלת
בדסקטופ (‏ctrl+גלילה). כאן ההתערבות קטנה מהתלות.

## איפה זה מופעל

| מפה | מופעל | למה |
|---|---|---|
| מפת החיפוש בדף הבית (`index.html`) | ✔ | המלכודת הגדולה — מפה בגובה מסך בראש הדף |
| מפת הנכס המוטמעת (`property.html`) | ✔ | 230px באמצע דף ארוך |
| מפת החלקה ב-CRM (`crm.html`) | ✔ | 280px בתוך פאנל נגלל |
| מפת המסך המלא בדף הנכס | ✘ | אין דף מתחת לגלול — המפה היא כל המסך |
| כלי סימון השכונות (`neighborhood-boundary.html`) | ✘ | עמוד בגובה מסך שלא נגלל, וכלי שדורש גרירה מדויקת |

## החלטות שכדאי לזכור

* **מגע בלבד.** התנאי הוא `pointer:coarse` / `hover:none` — מכשיר מגע, ולא
  "מסך צר". חלון דפדפן צר בדסקטופ נגלל בגלגלת ואין בו מלכודת. מחשב נייד עם מסך
  מגע שדיווח על עצמו כ-coarse משתחרר ברגע הנגיעה הראשונה בעכבר, והמפה חוזרת
  להתנהגות מלאה.
* **הגלגלת נשארת בטיפול נפרד.** `scrollWheelZoom:false` ואז הפעלה ב-`focus`
  היא המקבילה בדסקטופ. מפת החלקה ב-CRM קיבלה את הטיפול הזה עכשיו — קודם
  הגלגלת מעליה קירבה את המפה במקום לגלול את הפאנל.
* **הזזה בשתי אצבעות היא עדיין חיפוש.** `moveend`/`zoomend` נורים כרגיל, ולכן
  הפאנל המפוצל וסינון התחום הנראה בדף הבית לא הושפעו.
* **הבועית היא `aria-hidden`.** היא הסבר חזותי למי שגורר/ת באצבע; מי שמנווט/ת
  בקורא מסך לא מגיע/ה למצב הזה בכלל.
* **בלי הקובץ** (נכשל בטעינה) — הקריאה עטופה ב-`if (window.MapGestures)`,
  והמפה נשארת בדיוק כפי שהייתה. אותו עיקרון כמו שאר התלויות באתר.
* **מפה שנבנית מחדש על אותו `div`** (מפת החלקה ב-CRM, בכל חיפוש) מנקה את
  עצמה: המודול מאזין ל-`unload` של Leaflet, מסיר את הבועית ואת המאזינים ומאפשר
  הפעלה מחדש על המופע הבא.
