# סוג הבעלות בקרקע (טאבו)

לכל גוש/חלקה מוסדרים בישראל - סוג הבעלות הרשום בפנקסי המקרקעין: פרטית,
מדינה, רשות מקומית, מעורבת או אחר. המקור: משרד המשפטים, מאגר "סוג בעלות
בנכסים הרשומים בפנקסי המקרקעין" ב-data.gov.il (‏`tabu_asset`).

**המידע אינו קובע זכות משפטית** - כך המקור עצמו מציין. כל מקום שמציג אותו
אומר זאת, ומפנה לנסח טאבו.

## למה זה שווה משהו

"קרקע מדינה" פירושה בפועל חכירה מרשות מקרקעי ישראל ולא בעלות: העברה
עשויה לדרוש הסכמת רמ"י, לפעמים דמי היתר, וזה משפיע על המשכנתא. לקונה
זה משנה את העסקה, ולסוכן/ת זו שאלה שחוזרת.

**וזה לא מקרה שולי.** ב-26.9.2026 נבדקו 15,191 העסקאות של רשות המיסים
שבמסד מול המאגר:

| | |
| --- | --- |
| נמצאו במאגר | 90.7% |
| עפולה, חיפה, כרמיאל, קריית מוצקין, טירת כרמל | 99% ומעלה |
| נוף הגליל | 40% - חלקת פרויקט אחת (16547/5, ‏640 עסקאות) עוד לא רשומה |
| על קרקע מדינה, מתוך מה שנמצא | כ-35%. בכרמיאל יותר ממחצית, במגדל העמק שני שלישים |

## מה נטען, ומה לא

הקובץ הוא 2.87 מיליון שורות, שורה לכל **תת-חלקה** (דירה). הטבלה היא שורה
לכל **חלקה**:

| | |
| --- | --- |
| שורות בקובץ | 2,871,414 |
| לא מוסדרות - דולגו | 101,635 |
| פגומות - נדחו | 0 |
| **חלקות בטבלה** | **1,087,238** |
| חלקות שבהן יותר מסוג בעלות אחד | 37,993 (3.5%) |

**איחוד לחלקה:** ב-96.5% מהחלקות כל התת-חלקות באותו סוג. בשאר נשמר הסוג
הנפוץ, ו-`mixed_units = true`. בשוויון נבחר הסוג שמחייב בדיקה (מדינה לפני
פרטית), כי להשמיט "מדינה" מחלקה חצויה גרוע מלהזכיר אותה.

**רק מוסדר.** שורות עם "תיאור שיטה" (גוש שומה, ספר-דף, זכויות ירדני) הן
מספור אחר: ‏171 מהן מתנגשות במספר גוש/חלקה מוסדר, ו-116 בסוג בעלות **אחר**.
צירוף שלהן היה מחזיר לעסקה את הבעלות של חלקה אחרת. העסקאות, ה-GIS
ו-GovMap משתמשים במספור המוסדר.

**היעדר אינו "פרטית".** חלקה שאינה בטבלה היא קרקע לא מוסדרת, חלקה שעוד
לא נרשמה (כמו 16547/5), או טעינה שעוד לא רצה. כל מי שקורא את הטבלה מציג
"לא ידוע" ולא מסיק.

## הטעינה

| | |
| --- | --- |
| workflow | `.github/workflows/land_ownership.yml` - ה-3 בכל חודש, וידני |
| טוען | `land_ownership_loader.py` |
| בדיקות | `scripts/land_ownership_test.py` - רצות לפני ההורדה |
| טבלאות | `land_ownership` (גוש, חלקה, סוג, `mixed_units`, `batch`), `land_ownership_loads` (יומן) |
| מיגרציה | `20270115090000_land_ownership.sql` |

1. **CKAN** (`resource_show`) נותן את כתובת הקובץ ואת תאריך העדכון שלו.
   **אם הוא זהה לטעינה האחרונה שהצליחה - יוצאים בלי לכתוב.** מיליון upsert
   על נתונים שלא זזו הם רק bloat.
2. הורדה, ובדיקת הכותרת: עמודה שזזה הייתה ממפה "חלקה" ל"תת חלקה" בשקט.
3. צמצום לחלקות. **מעל 1% שורות פגומות - ההרצה נכשלת:** זה כבר פורמט אחר.
4. כתיבה במנות של 5,000, כל שורה עם ה-`batch` של ההרצה.
5. ‏`land_ownership_finish` מוחקת את השורות מההרצות הקודמות - **רק אם נכתבו
   לפחות 900 אלף חלקות.** הורדה שנקטעה היא CSV תקין עם חצי מהשורות, ובלי
   הסף "הצלחה" הייתה מוחקת חצי מדינה.

כשל בכל שלב משאיר את הנתונים הקודמים כמו שהם.

**הרצה ראשונה אחרי המיזוג:** Actions → "סוג בעלות בקרקע - טאבו" → Run
workflow. אם data.gov.il חוסם את השרתים של GitHub, אפשר להעביר כתובת
חלופית ב-`source_url`.

## מי קורא

| קורא | איך |
| --- | --- |
| העוזר בוואטסאפ, `planning_lookup` | `land_ownership_of(גוש, חלקה)`. **ארצי** - גוש/חלקה מחוץ לעפולה מחזירים בעלות גם כשאין ייעוד |
| העוזר בוואטסאפ, `planning_info` | אותה פונקציה, רק על נכס של הסוכן/ת - בכל נכס אחר הגוש והחלקה מצונזרים |

הגישה: ‏RLS בלי policy, ו-`revoke` מ-`anon` ו-`authenticated`. שתי
הפונקציות ‏`service_role` בלבד. אין קריאה מהדפדפן.

**הבוט מקבל הנחיה ולא רק נתון** (`OWNERSHIP_GUIDANCE` ב-`agent.ts`): מה
לומר על "מדינה", לציין את תאריך הנתונים ושהמידע אינו קובע זכות, ו**לא**
להסיק "פרטית" מהיעדר.

## גודל

הערכה: 60-80MB עם האינדקס, לעומת 112MB של כל המסד ב-26.9.2026. הקובץ
המצומצם עצמו הוא 15.9MB (‏2.9MB דחוס). חיפוש לפי המפתח `(gush, helka)`
הוא אותו זמן בטבלה של מיליון שורות ושל אלף, ולכן אין חלוקה לאזורים - גם
כי בקובץ אין שדה עיר או אזור לחלק לפיו.
