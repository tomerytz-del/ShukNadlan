# הניווט בכותרת של דף הנכס

עד אוקטובר 2026 הכותרת של `property.html` הייתה הלוגו ו"כל הנכסים" בלבד. זה
הדף הנצפה ביותר באתר, ורבים מגיעים אליו מקישור ששותף בוואטסאפ - גולש/ת שלא
מכיר/ה את האתר, ומתווך/ת שלא מצא/ה איך מצטרפים.

| רוחב | מה מוצג |
| --- | --- |
| עד 640px | לוגו, "הצטרפות למתווכים" (‏`/agency-signup`, קטן) וכפתור התפריט (מתחת ל-340px - בלי ההצטרפות, היא בתפריט) |
| 640-1100px | אותו דבר, עם המילה "תפריט" |
| מ-1100px | + שישה קישורים: למכירה, להשכרה, מסחרי, פרויקטים, משרדי תיווך, מחירי דירות |

התפריט הוא `<details>` - נפתח בלי JS, ונסגר בלחיצה מחוצה לו וב-Escape (סקריפט
קטן בסוף הדף). כל כלל ב-CSS נושא `header.site`, כי `design-system.css` נטען
אחרי ה-`<style>`. הקישורים לעמודי תוצאות הם מתוך `SEARCH_PAGES`
(‏`check_canonical.py`), ולכן "להשכרה" הוא `/?deal=rent&maxPrice=4000`.
