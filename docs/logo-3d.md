# האות שי״ן המסתובבת — לוגו הפלטפורמה

הלוגו שבפינה העליונה של כל דף אינו עוד עיגול שטוח אלא אות **שי״ן** מוזהבת
שמסתובבת לאט סביב הציר האנכי שלה, קדימה ואחורה, עם עומק אמיתי.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `assets/logo-shin-3d.png` | האות עצמה — 256×256, רקע שקוף, ~90KB |
| `assets/logo-3d.js` | הרכיב. מזריק את ה-CSS ובונה את הערימה. אין תלויות |

הלוגו העגול הישן, `assets/logo-shuknadlan.png`, נשאר בשימוש בשני מקומות שבהם
אין כותרת אתר: תמונת ברירת המחדל של כרטיסי נכסים (`SITE_LOGO` ב-`index.html`)
ודוח השוואת השוק להדפסה ב-`crm.html`.

## איך זה עשוי

אין כאן WebGL ואין ספריית תלת־ממד. התמונה נערמת 24 פעמים על ציר ה-Z בתוך
`transform-style:preserve-3d`, וכשהערימה מסתובבת השכבות הפנימיות נחשפות
בצדדים ויוצרות דופן.

שתי השכבות החיצוניות בלבד הן התצלום עצמו — הפאה הקדמית והאחורית. כל מה
שביניהן הוא צללית שטוחה: התמונה משמשת כמסכה (`mask`) על גרדיאנט זהב. זה
מהותי — אילו גם הדופן הייתה התצלום, ההבהקים האפויים בו היו נמרחים לפסים
ובזוויות גדולות האות הייתה נראית מרוחה במקום מוצקה.

### למה תנודה ולא סיבוב מלא

אות היא גוף דק. בסיבוב של 360° היא עוברת פעמיים במצב "פרופיל", מתכווצת
לרסיס ונעלמת כמעט לגמרי. בלוגו קטן בכותרת זה נקרא כהבהוב תקול ולא
כתלת־ממד. לכן התנועה מוגבלת ל-±30°, שבהם האות נשארת קריאה כל הזמן והעומק
עדיין נראה במלואו.

לסיבוב מלא, אם בכל זאת רוצים אותו — ב-`assets/logo-3d.js`:

```js
var SWING_DEG = 360;
var ALTERNATE = false;
```

## שילוב בדף חדש

שתי שורות, בלי לגעת במבנה:

```html
<img data-shin3d src="assets/logo-shin-3d.png"
     alt="שוק הנדל״ן של עפולה והסביבה" width="256" height="256">
...
<script defer src="assets/logo-3d.js"></script>
```

התגית `<img>` נשארת במקומה ומחזיקה את הגודל, את הקישור ואת ה-`alt` לקוראי
מסך; הסקריפט רק מניח מעליה שכבת תלת־ממד ומעלים את התמונה השטוחה. הגודל
נגזר מהתמונה בזמן ריצה דרך `ResizeObserver`, ולכן אותו רכיב עובד גם ב-46px
בנייד, גם ב-54px בדסקטופ וגם ב-64px בדפי ההרשמה — בלי הגדרה נוספת.

## התנהגות בקצוות

* **הסקריפט לא רץ** — מוצגת שי״ן סטטית. לוגו תקין לכל דבר, בלי קפיצת פריסה.
* **`prefers-reduced-motion: reduce`** — האות עומדת בזווית קבועה, בלי תנועה.
* **קוראי מסך** — שכבת התלת־ממד היא `aria-hidden`; ה-`alt` של התמונה הוא
  שנשמע.
* **הקישור לדף הבית** — השכבה היא `pointer-events:none`, ולכן הלחיצה עוברת
  אליו כרגיל.

## כוונון

הקבועים בראש `assets/logo-3d.js`:

| קבוע | ברירת מחדל | מה זה |
| --- | --- | --- |
| `SLICES` | 24 | שכבות בערימה. פחות מדי → רווחים בדופן |
| `DEPTH_RATIO` | 0.34 | עובי האות ביחס לגובה שלה |
| `TILT_DEG` | -7 | הטיה קלה מלמעלה. בלעדיה הסיבוב נקרא שטוח |
| `SWING_DEG` | 30 | עד כמה מסתובבת לכל צד |
| `SWING_SECONDS` | 9 | משך מעבר לכיוון אחד |
| `WALL` | גרדיאנט זהב | צבע הדופן |
