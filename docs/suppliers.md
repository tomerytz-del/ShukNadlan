# ספקים שמקבלים מידע מהמערכת

רשימת הספקים של הפלטפורמה: מה כל אחד מקבל, ומה המצב החוזי מולו. היא
משמשת שני קהלים: את מדיניות הפרטיות (`privacy.html`, ‏"ספקי תשתית"),
שחייבת לנקוב בכל אחד מהם, ואת ניהול הספקים בביקורת אבטחת מידע (ISO 27001,
נספח A, בקרות 5.19 עד 5.22).

**הכלל:** ספק חדש שמקבל מידע מהמערכת (מפתח API חדש ב-Supabase Secrets,
‏`fetch` לדומיין חדש בפונקציית Edge) נכנס לטבלה הזו **ולרשימה ב-
`privacy.html` באותו PR**. ספק שנוסף בלי זה הוא בדיוק הפער שנמצא
באוקטובר 2026: שישה ספקים שקיבלו מידע ולא הופיעו במדיניות.

**DPA** (הסכם עיבוד נתונים): לרוב הספקים יש הסכם מוכן שמאשרים בדשבורד
או באתר שלהם. "לבדוק / לחתום" פירושו שעוד לא תועד כאן שהוא אושר. כשמאשרים,
מחליפים בתאריך ובקישור.
