# תחום ואזורי פעילות

שלב 3 בעיצוב מחדש (`docs/handoff/crm-settings-redesign/HANDOFF.md`, סעיף 3.22).
סוכן/ת ומשרד בוחרים **באילו נכסים** (פרטיים / מסחריים ותעשייה / הכל) ו**באילו
אזורים** הם עובדים, ולפי זה נקבע במה משתפים אותם ועל מה מגיעה התראה.

**זה לא "תחומי התמחות".** תחומי ההתמחות (`agency_members.specialties`) הם תגיות
לתצוגה בדף הסוכן/ת, ואין קוד שמפרש אותן. תחום ואזורי פעילות הם העדפת עבודה
שמשנה מה מגיע אל הסוכן/ת (החלטה של תומר, 20.10.2026).

| איפה | מה |
| --- | --- |
| `assets/crm-areas.js` | `AreaPicker` - רכיב אחד לפרופיל (`#pfAreas`) ולדף המשרד (`#brAreas`) |
| `agency_members.service_markets`, `property_scope` | של הסוכן/ת. ‏`property_scope` null = כמו המשרד |
| `agencies.service_markets`, `property_scope` | ברירת המחדל של המשרד |
| `agent_share_fit(agent, category, city_id)` | האם נכס מתאים לסוכן/ת. ‏`EXECUTE` ל-`authenticated` (לא ל-`anon`) — בלי זה "שותפו איתי" חוזר 403 |
| `shared_properties_for_me.fits_me` | אותה שאלה, לכל נכס ב"שותפו איתי" |
| `share_property_for_agent` | ההתראה על נכס ששותף - רק למי שמתאים |
| מיגרציה `20270711090000_area_scope.sql` | כל השינויים במסד. ‏`20270903090000` מחזירה `EXECUTE` ל-`authenticated` |

## משרד וסוכן/ת

- **אזורים מתמזגים:** של המשרד ועוד של הסוכן/ת. סוכן/ת במשרד בעפולה שעובד/ת
  גם בחיפה מוסיף/ה את חיפה. בפרופיל אזורי המשרד מוצגים מסומנים ונעולים, עם
  התגית "מהמשרד", ונשמרים רק האזורים של הסוכן/ת.
- **סוג הנכס של הסוכן/ת גובר** כשנבחר, אחרת של המשרד. איחוד כאן היה מבטל בחירה
  של "פרטיים בלבד" במשרד שעובד בהכל.

## מה זה משנה, ומה לא

| | |
| --- | --- |
| **"שותפו איתי"** | הצ'יפ "באזורי הפעילות שלי" דלוק כברירת מחדל, ומוצג רק כשיש נכס מחוץ להם. קישור ישיר לנכס כזה מכבה אותו |
| **התראה על נכס ששותף** (`system`) | רק למי שהנכס מתאים לו/ה - בפעמון ולכן גם בוואטסאפ |
| **השיתוף עצמו** (`property_shares`) | **לא משתנה.** ההתאמות ללקוחות ממשיכות למצוא נכסים מכל הרשת |
| **דף האזור באתר** | כמו קודם: לפי `agency_members.service_markets`. אזורי המשרד (`agencies.service_markets`) עוד לא נקראים באתר |

**נכס מתאים** כשאין אזורים בכלל (לא סוכן/ת ולא משרד), כשהעיר שלו אינה ידועה או
אינה בשום שוק - לא מסתירים מה שאי אפשר לשייך - או כשהשוק של העיר
(`cities.market_slug`) באזורים. "פרטיים" = כל מה שאינו `category = 'commercial'`.

**ומה קורה ביום המיזוג:** 45 מתוך 56 הסוכנים הפעילים כבר בחרו אזורים (בעיקר עפולה
והעמק), בשביל הדף באתר. מרגע שהמיגרציה רצה הם מפסיקים לקבל התראה על נכס ששותף
מחוץ להם (כ-20 מתוך 227 הנכסים הפעילים, ב-20.10.2026). למשרדים אין עדיין אזורים -
**בלי backfill בכוונה**, כדי שהמיגרציה עצמה לא תשתיק אף אחד.

## שלוש הקבוצות

`AREA_REGIONS` ב-`assets/crm-areas.js` - צפון, מרכז, דרום. `assets/markets.js` אינו
נושא אזור, ושוק חדש שלא נרשם שם נכנס ל"עוד אזורים" ולא נעלם. ירושלים, בית שמש,
השומרון, בנימין וגוש עציון במרכז. אין "כל הארץ" (החלטה של תומר) - בלי אזורים
המשפט אומר "מכל הארץ".
