# חברה יזמית של פרויקט בנייה

טבלת `building_projects` שומרת איזו חברה בנתה בניין, ומקשרת אותו לנכס
ולגבריאלה. זה אינו דף הנחיתה של יזם (`projects` / `developers`): שם חברה
שנרשמה לאתר ומנהלת דף. כאן זה זיכרון על בניין קיים, גם בלי חשבון יזם.

הדגל `app_config.building_projects_enabled` נולד `false`. כבוי: אין שאלה,
אין תשובה מהטבלה, ודוח ה-CMA לא מקבל שורת יזם.

## מה נשמר

| שדה | משמעות |
| --- | --- |
| `developer_company` | שם החברה. ריק = לא ידוע |
| `partners` | שותפים, אם נמסרו |
| `source_type` | `web` / `agent` / `municipality` / `manual` |
| `verification_status` | `unverified` / `verified` / `conflict` |
| `addresses` | כתובות מדויקות, אחרי כיווץ רווחים |
| `source_note` | מאיפה השם, וגם ערך סותר שלא נרשם |

קריאה: סוכן/ת מחובר/ת (`current_agent_id()`). כתיבה: רק פונקציות השרת.

**התאמה לנכס היא מדויקת.** עיר, רחוב ומספר בית. אין קירוב של שם רחוב, ואין
קישור בלי ספרה במספר הבית. שתי שורות לאותה כתובת: לא מקשרים ולא בוחרים.

**שם קיים לא נדרס.** ערך אחר מסמן `conflict` ומשאיר את השם. "לא יודע" אינו
שם חברה.

## פיילוט רובע יזרעאל

שש שורות, `source_type = web`, `unverified`, בלי כתובות, ולכן עדיין לא
מקושרות לנכס:

| פרויקט | חברה | הערה |
| --- | --- | --- |
| שהם וטופז | אבני דרך | |
| עדן המושבה הקטנה | אלמוגים | |
| אדרת העמק | רם אדרת | |
| קדמת נופר | דר נופרים | |
| נוף בראשית | משולם לוינשטין | שותפים: אגדים, קימה ברזילי |
| פארק ATECH | קבוצת GRP | מסחרי, עתידי |

פרויקט שביעי לא נמצא בריפו ולא בתיעוד, ולא הומצא.

## גבריאלה

נכס חדש מקבלן, נכס חדש, או נכס עם `project_status` של פרויקט, בלי חברה
רשומה לכתובת: שאלה אחת בכפתור "לא יודע". הנכס נשמר לפני השאלה. אותה כתובת
לא נשאלת שוב.

השליחה רק כש-`notification_send_window_open` פתוח (כולל שישי עד 13:00
ושבת סגורה) ורק בתוך 24 השעות של וואטסאפ. מחוץ לחלון השאלה ממתינה
ל-`?task=building-developer-ask`. הכפתור נתפס לפני המודל. שם שהסוכן/ת
כותב/ת נשמר `source_type = agent`, `unverified`. אין ניחוש.

"מי בנה / מי היזם של הבניין ברחוב X" הוא `building_developer_lookup`.
בלי מספר בית אין שם. התשובה אומרת את המקור, ואומרת שהנתון לא אומת כשאינו
מאומת.

## דוח CMA

`cma_attach_building_developer` מוסיף ל-`subject` את החברה, השותפים,
המקור וסטטוס האימות, רק כשהדגל דלוק ויש התאמה. `renderCmaReport` מציג
את השורה. בלי השדות ב-JSON אין שורה.
