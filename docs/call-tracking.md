# יומן שיחות: מספר, הקלטה, תמלול וסיכום (פיילוט Twilio)

לקוח/ה מתקשר/ת למספר של Twilio שמשויך לסוכן/ת. השיחה מנותבת לנייד של
הסוכן/ת ומוקלטת, ובסופה הסוכן/ת מקבל/ת בוואטסאפ סיכום של השיחה ואת
ההקלטה, והשיחה נכנסת ליומן ב-CRM.

**למה דרך Twilio:** דפדפן אינו רואה את יומן השיחות של הטלפון בשום מכשיר
(`crm-contacts-import.md`), ולכן יומן אמיתי מחייב שהשיחה תעבור דרכנו.
ההשוואה מול Voicenter וההחלטה: Twilio מאפשרת להקצות מספרים מהקוד, בתשלום
לפי שימוש, ואת התמלול והסיכום אנחנו עושים בעצמנו בכל מקרה.

## הזרימה

```
לקוח/ה ──► מספר Twilio ──► twilio-voice?event=incoming
                              │  הודעת הקלטה (Google TTS, עברית)
                              │  <Dial record> לנייד של הסוכן/ת, callerId = המתקשר/ת
                              ▼
                        ?event=dial ── לא נענתה ──► "נחזור אליכם" + וואטסאפ לסוכן/ת
                              │
                        ?event=recording
                              │  הורדה ← דלי call-recordings ← מחיקה מ-Twilio
                              │  Whisper ← Claude (סיכום, שם, דרישות, צעד הבא)
                              ▼
                        וואטסאפ לסוכן/ת: סיכום + קובץ שמע · שורה ב-agent_calls
```

| רכיב | איפה |
| --- | --- |
| הפונקציה | `supabase/functions/twilio-voice/index.ts` (‏`verify_jwt = false`) |
| הטבלאות | `agent_phone_lines`, `agent_calls` - מיגרציה `20270202090000_call_tracking.sql` |
| ההקלטות | דלי פרטי `call-recordings/<agent_id>/<call_id>.mp3` |
| ה-CRM | בלוק "שיחות אחרונות" בקובץ הלקוחות (`loadCalls` ב-`crm.js`), עם עדכון כרטיס וסימולציה |
| העוזר | הכלי `list_calls` ב-`whatsapp-webhook/agent.ts` |
| המחיקה | cron יומי `call-recordings-cleanup` ← `twilio-voice?task=cleanup` |
| פרטיות | `privacy.html#calls` |

## ארבעה כללים

1. **כל וובהוק מאומת בחתימה.** ‏`X-Twilio-Signature` מחושבת על הכתובת
   **החיצונית** (`SUPABASE_URL/functions/v1/twilio-voice?...`) ולא על
   `req.url`, שבתוך ה-Edge Runtime אינה זהה. בלי `TWILIO_AUTH_TOKEN` הפונקציה
   עונה 503 ואינה מעבדת כלום.
2. **מספר בלי שורה פעילה ב-`agent_phone_lines` עונה בהודעה ומנתק.** הוא לעולם
   אינו "נופל" לסוכן/ת אחר/ת. אין ממשק הקצאה: בפיילוט השורה נכתבת במיגרציה.
3. **העותק היחיד של ההקלטה אצלנו, עם תאריך תפוגה אחד.** היא נמחקת מ-Twilio מיד
   אחרי ההעתקה, ומאיתנו אחרי **90 יום**. התמלול והסיכום נשארים בשורה.
   המחיקה עוברת דרך ה-Storage API ולא ב-SQL, כי מחיקת שורה מ-`storage.objects`
   משאירה את הקובץ עצמו יתום.
4. **בתוך חלון 24 השעות של וואטסאפ - טקסט ושמע; מחוצה לו - התבנית.** אותה
   תבנית של ההתראות (`WHATSAPP_NOTIFY_TEMPLATE`), עם הסיכום כשורה אחת וכפתור
   ל-CRM. תבנית אינה יכולה לשאת קובץ שמע, ולכן אז ההקלטה מחכה ב-CRM. קובץ מעל
   16MB אינו נשלח בוואטסאפ בכל מקרה.

## מהשיחה לכרטיס

הסיכום מחזיר גם `needs` - הדרישות **בשמות השדות של `agent_clients`**
(`deal_type`, `cities`, `min_rooms`, `min_price`, `max_price`), רק מה שנאמר
במפורש, ומנוקה בקוד (‏`cleanNeeds`: טווחים סבירים, מינימום שאינו עולה על
המקסימום). משם שלוש דרכים להגיע לכרטיס:

| איפה | מה |
| --- | --- |
| ה-CRM, לקוח/ה מוכר/ת | "🔄 עדכון הכרטיס מהשיחה" - ערים **בתוספת** לקיימות, ו-`paused` עובר ל-`active` |
| ה-CRM, מספר לא מוכר | "➕ הוספה לקובץ" ממלא שם, טלפון **ודרישות** בטופס |
| וואטסאפ | "כן, תעדכן" / "כן, תוסיף" אחרי הסיכום ← `list_calls` ← `update_client` / `create_client` |

**ולמה ערים בתוספת:** לקוח/ה שאמר/ה בשיחה "גם בעפולה" לא ויתר/ה על נצרת
שכבר בכרטיס. החלפה הייתה מוחקת דרישה בלי שאיש אמר את זה.

## העוזר בוואטסאפ: `list_calls`

"מי התקשר אליי היום", "מי לא נענה", "מה דיברתי עם דני" - קריאה מ-`agent_calls`
של הסוכן/ת בלבד, עם הסיכום וה-`needs` של כל שיחה. הכלי אינו ב-`EMAIL_TOOLS`:
לתור מייל אין סיבה לקרוא את יומן השיחות.

## סימולציה - כל הצינור בלי Twilio

ב-CRM, בבלוק "שיחות אחרונות", למנהל/ת הפלטפורמה בלבד: **"🧪 סימולציית שיחה"**.
מעלים הקלטה (הודעה קולית מוואטסאפ, הקלטה מהטלפון - ogg, m4a, mp3, wav, webm),
ואפשר לתת מספר של "מתקשר/ת" - מספר של לקוח/ה מהקובץ בודק גם את הזיהוי.
‏`twilio-voice?task=simulate` מאמת JWT ו-`is_platform_admin`, רושם שורה עם
`twilio_call_sid` שמתחיל ב-`SIM-`, ומריץ את אותו `analyzeCall` של שיחה אמיתית:
אחסון, תמלול, סיכום, הודעה בוואטסאפ. כך תקלה אחרי חיבור המספר היא של הטלפוניה,
ולא של הסיכום.

## הזיהוי

המתקשר/ת מזוהה/ת מול `agent_clients` לפי תשע הספרות האחרונות - אותו כלל של
`create_client` בעוזר ושל הייבוא מאנשי הקשר. לקוח/ה מוכר/ת נכתב/ת גם ל-
`whatsapp_conversations.last_client_id`, כדי ש"תעדכן לו את התקציב" אחרי הסיכום
יגיע לכרטיס הנכון. מספר לא מוכר מקבל בסיכום הצעה "תוסיף את 05... כלקוח",
וב-CRM כפתור "הוספה לקובץ" שממלא את הטופס (והדרישות שעלו בשיחה - בהערות).

## הקמה (פיילוט)

1. **Twilio:** חשבון בתשלום, Regulatory Bundle לישראל (Local, Business),
   וקניית מספר.
2. **סודות** ב-Supabase ← Edge Functions ← Secrets: `TWILIO_ACCOUNT_SID`,
   `TWILIO_AUTH_TOKEN`. התמלול משתמש ב-`OPENAI_API_KEY` והסיכום ב-
   `ANTHROPIC_API_KEY`, שכבר מוגדרים.
3. **המספר ב-Twilio** ← Voice Configuration ← *A call comes in*: Webhook,
   `https://obookujgolazrwycsiyn.supabase.co/functions/v1/twilio-voice?event=incoming`,
   ‏HTTP POST.
4. **שורה ב-`agent_phone_lines`** במיגרציה: `agent_id`, `twilio_number`
   (E.164, כמו שמופיע ב-Twilio), ו-`forward_to` אם הניתוב אינו לטלפון הרשום.

## בדיקה ידנית

* שיחה למספר מטלפון אחר, מענה בנייד, כמה משפטים ("מחפשים 4 חדרים בעפולה עד
  2 מליון"), ניתוק ← תוך דקה: סיכום ושמע בוואטסאפ, ושורה ב"שיחות אחרונות".
* שיחה בלי מענה ← הלקוח/ה שומע/ת "נחזור אליכם", והסוכן/ת מקבל/ת התראה.
* ‏`select status, summary, error from agent_calls order by created_at desc limit 5`
  - `error` הוא המקום הראשון לחפש בו כשמשהו לא הגיע.

## מה עוד לא כאן

שיחות יוצאות (Click2Call) · הקצאת מספר מהממשק · יכולת לפי מסלול (גייט במסד,
שורה ב-`pricing.html` - סקיל `new-tier-capability`) · תא קולי כשאין מענה.
