# הוראות לסוכן הסורק - לידים מקבוצות פייסבוק ומרקטפלייס

עודכן: 25.10.2026. המקור המלא: `docs/scraped-leads.md`. כשמשהו כאן משתנה,
מעדכנים את הקובץ הזה באותו PR.

## מה השתנה עכשיו (תקופת השקה עד 25.1.2027)

- **כל פוסט שנקלט מוצג מיד לסוכנים בעיר כ"ביקוש פתוח" אנונימי**, במקביל לבקשת
  ההסכמה שלך. לא צריך לחכות 7 ימים.
- סוכן/ת אחד/ת לוחץ/ת "אני פונה", והביקוש יורד מהרשימה של כל השאר. **אם האדם
  מסכים/ה אחר כך, הליד הולך לסוכן/ת שפנה/תה.**
- ליד אחרי הסכמה ניתן לסוכן/ת **בחינם** בתקופת ההשקה, וליד בעלים גם לסוכנים
  במסלול Pay&GO.
- **הסוכנים רואים רק:** סוג (מחפש/ת או בעלים), עסקה, עיר ושכונה, סוג נכס, חדרים,
  תקציב או מחיר, `summary`, הקישור לפוסט ותאריך הפרסום. **לא** שם, לא טלפון, לא
  הטקסט המלא ולא `property_details`.

## הקריאות

שלוש פונקציות, דרך `execute_sql` עם `select` (או `/rest/v1/rpc/` עם מפתח service role):

```sql
select public.scraped_lead_add('{
  "lead_type": "seeker_inbound",            -- או owner_inbound
  "source": "facebook_group",               -- או facebook_marketplace
  "source_detail": "דירות להשכרה בעפולה",   -- השם האמיתי של הקבוצה, לא מספר
  "external_ref": "https://www.facebook.com/groups/123/posts/456/",
  "posted_at": "2026-10-24T09:12:00+03:00", -- עד 72 שעות אחורה
  "raw_name": "...", "raw_phone": "...", "raw_message": "...",
  "city": "עפולה", "neighborhood": "גבעת המורה",
  "deal_type": "rent", "property_type": "דירה",
  "rooms": 4, "budget": 5500, "move_in": "מיידי",
  "summary": "זוג עם שני כלבים, טווח ארוך",
  "consent_requested": true
}'::jsonb);

select public.scraped_lead_set_consent('<id>', 'requested');  -- שלחת בקשת הסכמה
select public.scraped_lead_set_consent('<id>', 'consented');  -- הסכים/ה
select public.scraped_lead_set_consent('<id>', 'declined');   -- סירב/ה (נמחק ונחסם)

-- השלמת שדות בפוסט שכבר נקלט (למשל 6 הרשומות הראשונות). רק השדות ששולחים מתעדכנים.
select public.scraped_lead_enrich('<id>', '{
  "summary": "...", "budget": 1245000, "rooms": 4, "move_in": "...",
  "property_type": "דירה", "deal_type": "sale",
  "source_detail": "השם האמיתי של הקבוצה", "neighborhood": "גבעת המורה"
}'::jsonb);
```

**לא לעדכן את הטבלה ישירות** (`update scraped_leads ...`). ‏`scraped_lead_enrich`
עובדת רק על פוסט שממתין להסכמה או שהוא ביקוש פתוח, ולא נוגעת בשם, בטלפון
ובטקסט. ה-id של כל רשומה מופיע בתשובה של `scraped_lead_add` (גם ב-`duplicate`).

## איך ממלאים - חשוב

| שדה | כלל |
| --- | --- |
| `summary` | **חדש, ומוצג לכל הסוכנים בעיר.** עד 160 תווים: מה מחפשים או מה מציעים. **בלי שם, טלפון, רחוב, מספר בית או קישור.** "זוג עם 2 כלבים, טווח ארוך" - כן. "דירה ברח׳ סטרומזה 7" - לא |
| `budget` | התקציב של מחפש/ת, **והמחיר המבוקש של בעלים**. למלא מספר גם כשהמחיר כתוב רק בטקסט (‏"1,245,000 ₪" ← `1245000`) |
| `source_detail` | השם של הקבוצה כפי שמופיע בפייסבוק. משמש גם לזיהוי קבוצה "ללא תיווך" |
| `property_details` | מותר בו פירוט (כולל כתובת): הוא נחשף רק לסוכן/ת שקיבל/ה את הליד אחרי הסכמה. לא שם, לא טלפון, לא קישור |
| `property_type` | כמו בהעדפות הסוכנים: `דירה`, `דירת גן`, `בית פרטי`, `מסחרי`... |
| `deal_type` | `sale` או `rent` בלבד |
| `city` | שם עיר כפי שהוא במערכת. תשובה עם `city_known: false` - לתקן את השם ולשלוח שוב, אחרת אף סוכן/ת לא יראה את הפוסט |
| `no_broker` | לא חובה. אפשר לשלוח `true` כשברור מהפוסט שלא רוצים מתווכים; המסד מזהה "ללא תיווך" גם לבד, בטקסט ובשם הקבוצה |

## "ללא תיווך"

- **בעלים** שכתבו "ללא תיווך" (בפוסט או בקבוצה "ללא תיווך") - **כן לקלוט.** הם
  מוצגים לסוכנים עם סימון והנחיה לפנות בהודעה פרטית עם הצעה לשיווק מקצועי.
- **מחפשים** שכתבו "ללא תיווך" - אפשר לקלוט בשביל מסלול ההסכמה, אבל הם **לא**
  יוצגו כביקוש פתוח.

## התשובה של `scraped_lead_add`

- `{success, id, status, city_known, no_broker, open_demand}`. ‏`no_broker` הוא
  `post`, `group` או `null`. ‏`open_demand: true` - הפוסט מוצג עכשיו לסוכנים.
- `{duplicate: 'post' | 'declined' | 'phone' | 'lead'}` - לא לשלוח שוב ולא לבקש
  הסכמה שוב.
- `{error}`: `invalid_lead_type`, `invalid_source`, `missing_post_url`,
  `missing_city`, `missing_phone`, `missing_posted_at`, `post_too_old`,
  `invalid_deal_type`.

## מה לא השתנה

- לא כותבים ישירות ל-`leads`. רק שלוש הפונקציות שלמעלה.
- סירוב: לסמן `declined` מיד. הפוסט נמחק, יורד מהביקוש הפתוח, ולא ייקלט שוב.
- בלי תשובה 7 ימים: השם, הטלפון והטקסט נמחקים, והביקוש נשאר עד 30 יום מהפרסום.
- פוסט מלפני יותר מ-72 שעות נדחה.
