# דף 404

עד אוקטובר 2026 כל כתובת שאינה קיימת קיבלה את דף ברירת המחדל של Netlify -
באנגלית, בלי מיתוג ובלי דרך להמשיך. מי שנחת/ה מקישור ישן למודעה שירדה פשוט
עזב/ה. ‏`404.html` בשורש הוא הדף ש-Netlify מגיש מעצמו, עם סטטוס 404, לכל
כתובת שאין לה קובץ ואין לה שורה ב-`_redirects` (וגם לשורות `404!` שם).

| מה בדף | למה |
| --- | --- |
| שדה חיפוש (‏`action="/"`, ‏`name="q"`) | ממשיך לחיפוש של דף הבית, אותו מפענח (‏`search-core`) |
| שמונה קישורים לדפים המרכזיים | מכירה, השכרה, מסחרי, פרויקטים, מחירים, משרדים, מבזקים, הצטרפות למשרד |
| כרטיס "שיחה עם גבריאלה" | פותח את החלונית הצפה (‏`gabriela-widget.js`, ‏`data-page="page"` → ‏`site`). כשהעוזרת כבויה הכרטיס נשאר מוסתר |
| הפוטר המלא | כמו בכל דף תוכן |

## מה שונה מדף רגיל

* **`<base href="/">`** מיד אחרי קטע ה-GTM. הדף מוגש בכל נתיב (‏`/a/b/c`), ובלי
  זה `assets/x.js` היה נפתר ל-`/a/b/assets/x.js` והדף היה עולה בלי עיצוב.
* **‏`noindex,follow`, בלי `canonical` ובלי שורה ב-`sitemap.xml`** - הוא ב-`PRIVATE`
  של `scripts/check_canonical.py`.
* **קישור לעמוד תוצאות** חייב להיות אחד מ-`SEARCH_PAGES` (‏`check_canonical.py`
  סורק כל `href="/?..."`), ולכן "דירות להשכרה" מקשר ל-`/?deal=rent&maxPrice=4000`.
* העיצוב ב-`assets/not-found.css`, מעל `content-page.css`.
