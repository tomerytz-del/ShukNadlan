## איך לקרוא את הקבצים

- כל קובץ הוא תבנית: markup בתוך `<x-dc>`, ומחלקת JS קטנה בסוף (`renderVals()`) שמחזירה את הנתונים.
- `{{hole}}` = ערך מ-`renderVals()`. `<sc-for list="{{x}}" as="i">` = לולאה. `<dc-import name="AdminSidebar">` = שילוב קובץ אחר באותה תיקייה.
- **הנתונים ב-`renderVals()` הם נתוני הדגמה.** אמיתיים רק: 16 משרדים, 34 סוכנים, 32 לידים, ₪90 הכנסות. `[X]` / `[n]` / `[שם...]` = לחבר לנתון אמיתי.
- **לא מעתיקים את הקוד.** לוקחים מבנה, היררכיה, ניסוח, צבעים ומידות, ובונים בדרך המקובלת בריפו (`crm.html` + `assets/*.js`).
- כרטיס "כלל הפתיחה של שוק" ב-`Admin-Growth.dc.html` מציג מקומות ריקים לתנאים, כי הכלל כבר קיים במערכת (החלטה 1).
- בקבצים יש תווים כמו `·` ו-`−` (סימן מינוס בארנק). אין בהם מקף ארוך.
