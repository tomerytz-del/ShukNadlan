# התחל כאן: שדרוג אזור מנהל הפלטפורמה (שוק נדל״ן)

## מה יש בתיקייה

| קובץ | מה זה |
| --- | --- |
| `START-HERE.md` | הקובץ הזה: איך מתחילים, והפרומפט לקלוד קוד |
| `HANDOFF.md` | מסמך ההעברה המלא: החלטות, שלבים, מסד, בדיקות, סדר ביצוע ושאלות פתוחות |
| `design/SCREENS.md` | רשימת המסכים ואיך לקרוא את קובצי העיצוב |

## איך מתחילים

1. להעתיק את התיקייה `shuknadlan-admin-redesign` לריפו `tomerytz-del/ShukNadlan` בנתיב `docs/admin-redesign/`.
2. לפתוח את קלוד קוד בשורש הריפו.
3. להדביק את הפרומפט שבהמשך. הוא מתחיל בשלב 1 בלבד (תיקון "שווקים מקומיים"). כל שלב הבא הוא PR נפרד, באותו פרומפט עם מספר השלב.

## הפרומפט לשלב הראשון

```
קרא את docs/admin-redesign/HANDOFF.md עד הסוף, ואת docs/admin-redesign/design/SCREENS.md.
אחר כך קרא את CLAUDE.md ואת הסקילים והמסמכים שמופיעים ב"לפני שמתחילים" במסמך.

אנחנו בונים את שלב 1 מסעיף 12 ("סדר ביצוע"): תיקון "שווקים מקומיים" (סעיף 5 במסמך).

לפני שאתה כותב קוד:
1. אתר בקוד ובמסד את מה שמסומן "לאמת" בסעיף 5: הפונקציה שמחזירה את נתוני האזורים,
   הכלל הקיים לפתיחת שוק, ולמה הטעינה נכשלת (לוגים, זמני ריצה).
2. כתוב לי בקצרה מה מצאת ואת התוכנית ל-PR, כולל המיגרציות.
3. חכה לאישור שלי.

כללים: מיגרציות רק דרך הצינור (CLAUDE.md), PR אחד לשלב, לעדכן את המסמך שב-docs/ של היכולת,
ולהריץ את הבדיקות של השלב מסעיף 11. אם משהו במסמך סותר את מה שמצאת בקוד, תעצור ותשאל.
```

## לשלבים הבאים

אותו פרומפט, ובשורה השנייה להחליף את מספר השלב ושמו לפי סעיף 12 במסמך:

1. תיקון שווקים מקומיים (סעיף 5)
2. ניווט (סעיף 2)
3. תיבת משימות (סעיף 4)
4. מרכז הפיקוד (סעיף 3)
5. תזכורת לאימות רישיון (סעיף 7)
6. שווקים וצמיחה (סעיף 6)
7. עלויות מול תקציב (סעיף 10)
8. תיאורי שכונות עם AI (סעיף 8)
9. מאמן AI למנהל הפלטפורמה (סעיף 9)
