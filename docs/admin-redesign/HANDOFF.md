### 2.2 התנהגות

- **קבוצה נפתחת ונסגרת** בלחיצה על הכותרת (`<button aria-expanded>`). הקבוצה של הפריט הפעיל תמיד פתוחה. המצב נשמר ב-`localStorage` (‏`adminNavOpen`), עטוף ב-try/catch.
  ברירת מחדל: "היום", "שוק ומשתמשים", "צמיחה ושיווק" ו"כסף" פתוחות, השאר מקופלות.
- **קבוצה מקופלת מציגה שורת תקציר** (שמות הפריטים) **ומונה מסוכם.** מונה אדום (`#C2410C`) = יש בה פריט שחרג מזמן היעד (סעיף 4). מונה כהה = יש פריטים שממתינים בתוך הזמן.
  כך שום דבר דחוף לא מתחבא בקבוצה סגורה.
- **מונים על פריטים:** מאותו מקור של תיבת המשימות (`admin_inbox_counts()`, סעיף 4.2), בקריאה אחת בעלייה ולא שאילתה לכל פריט (`crm-startup`).
- **מתג "תצוגת סוכן/ת / ניהול פלטפורמה"** עובר מראש התוכן לראש התפריט.
- **"פעולה מהירה"** (מקש `N`): רשימת הפעולות של "כלי עבודה ופרסום" (סעיף 3.2). כל פריט פותח מסך או פעולה **שכבר קיימים**. פעולה שאין לה מימוש לא מוצגת.
- **חיפוש `Ctrl K`** בראש העמוד: משרד, סוכן/ת, ליד, נכס, הגדרה. **לאמת** אם יש היום חיפוש אדמין. אם לא, RPC‏ `admin_search(p_q, p_limit)`, `security definer`,
  שבודק בשורה הראשונה שהקורא/ת אדמין (בפונקציה הקיימת שמזהה אדמין, **לאמת את שמה**). ספירה במסד, מינימום 2 תווים, debounce של 250ms.
- **בתחתית:** מצב גבריאלה (שיחות ושגיאות היום, מאותו מקור של "גבריאלה היום" בדוח החודשי), עזרה, וכיווץ לפס אייקונים של 72px (‏`adminNavRail`).

### 2.3 נייד

`Admin-Mobile.dc.html`: סרגל תחתון **מרכז · משימות · + · צמיחה · חיפוש**. כפתור ההמבורגר בכותרת פותח את התפריט המלא.
**לאמת** קישור עמוק לכל קטגוריה של האדמין בנייד אחרי שהלשוניות יורדות.

| תיאור שכונה שנוצר ב-AI | סעיף 8 | פרסם / ערוך / דחה | כן |

### 4.2 במסד

- **`admin_inbox(p_type text default null, p_limit int default 50, p_offset int default 0)`** returns jsonb, `security definer`, בדיקת אדמין בשורה הראשונה (`42501`).
  איחוד (`union all`) של המקורות לשורות אחידות: `kind, ref_id, title, subtitle, created_at, waiting_minutes, sla_minutes, overdue bool`.
  **בלי טלפונים ובלי תוכן הודעות** בשורת הרשימה. חלון הפרטים קורא את הפריט מהמקור שלו, עם ההרשאות הקיימות.
- **`admin_inbox_counts()`** returns jsonb: `{kind: {total, overdue}}`. משמש את המונים בתפריט ואת מרכז הפיקוד. ספירה במסד.
- **זמני יעד** בטבלת הגדרות `admin_sla (kind text primary key, minutes int)`, שאדמין עורך מהכפתור "כללי זמן תגובה". ערכי פתיחה:

  | kind | יעד |
  | --- | --- |
  | ליד ללא יעד | 2 שעות |
  | בקשת החזר | 48 שעות |
  | ערעור רישיון | 12 שעות (תומר, 21.10.2026) |
  | ביקורת שסומנה | 12 שעות (תומר, 21.10.2026) |
  | כרטיס בעל מקצוע | 48 שעות (תומר, 21.10.2026) |
  | כתבה / בלוג | 72 שעות (תומר, 21.10.2026) |
  | חסר למנטור | 72 שעות (נוסף בבנייה: תור קיים שלא היה בטבלה) |

  **נבדק בבנייה (21.10.2026):** כרטיס בעל מקצוע, ביקורת שסומנה וכתבה לאישור אינם
  תורים שקיימים היום, ולכן שלב 3 בנה את התיבה על ארבעת התורים הקיימים. הפירוט:
  `docs/admin-inbox.md`.

- **חריגה מזמן היעד** = הפריט נצבע אדום, נכנס לספירת "דחופים", ונשלחת התראה לפעמון של האדמין פעם אחת לפריט (לא בכל טעינה).
  סוג התראה חדש לפי `agent-notifications` (ארבעה מקומות, אילוץ רק דרך `notification_types_add`).
- **יומן ביקורת:** כל החלטה מהתיבה נרשמת ביומן הביקורת הקיים, כולל "הערה פנימית" מחלון הפרטים.
- **הודעה לצד השני:** כל החלטה שולחת הודעה לפעמון של הסוכן/ת או המשרד (ובמייל, אם המקור שולח היום מייל).

### 4.3 בממשק

- צ'יפים לפי סוג, עם מונה. "הכל" ראשון.
- שורה: סוג, כותרת, תת-כותרת, זמן המתנה בצבע (ירוק = בזמן, צהוב = מעל חצי מהיעד, אדום = חרג), כפתור.
