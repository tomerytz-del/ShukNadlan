# שכבת החלקות הפתוחה (‏`parcels_open`)

עותק משלנו של שכבת **החלקות** של המרכז למיפוי ישראל, מהמאגר הפתוח
ב-data.gov.il ("חלקות shape", רישיון פתוח שמתיר שימוש מסחרי). ‏1,097,775
חלקות בכל הארץ: גוש, חלקה, שטח רשום, סטטוס (מוסדר / לא מוסדר), יישוב ורשות.

## למה, ולמה לא מ-GovMap

GovMap נותן את אותה שכבה (‏`PARCEL_ALL`), אבל מפ"י מתירים את ה-API **מצד
הלקוח בלבד**, ותנאי השימוש אוסרים איסוף בהיקף בלי אישור בכתב
([govmap.md](govmap.md), "תנאי השימוש"). לכן הבוט אינו יכול לשאול את GovMap,
ואסור למלא ממנו מטמון. המאגר הפתוח הוא אותו מידע, בהורדה מסודרת ומותרת.

**מה אין בשכבה:** ייעוד קרקע ותוכניות. הם נשארים ב-GovMap (שכבות 203/14),
לנכס בודד, בדפדפן - ותשובת הבוט מפנה אליהם בקישור לכלי ב-CRM. **הכיוון
להשלים אותם בשרת:** ‏XPlan של מינהל התכנון (שירות ArcGIS ציבורי, ומאגר
`xplan2` ב-data.gov.il) - בבדיקה ב-`scripts/iplan_probe.py`; המגבלות והאיסור
לבטל אימות תעודה - בסקיל `govmap`, סעיף 8.

## מה נשמר

| עמודה | |
| --- | --- |
| `gush`, `helka`, `gush_suffix` | המפתח. ‏`gush_suffix` הוא 0 כמעט תמיד; גוש עם סיומת הוא גוש אחר |
| `legal_area` | שטח רשום במ"ר. ‏0 במקור נשמר כ-`null` |
| `status_text`, `locality_name`, `municipality` | כמו במקור |
| `lat`, `lng` | מרכז הטבעת החיצונית, ב-WGS84. מחוץ לתיבת ישראל - `null` |

**נקודה ולא צורה:** מיליון מצולעים היו מאות MB במסד, והשימוש היום הוא "איפה
החלקה". כשיידרש "איזו חלקה מכילה את הנקודה" - זה יהיה PostGIS, ושינוי בטוען.

## הטעינה

‏`scripts/parcels_open_loader.py`, ב-workflow ‏`parcels_open.yml`: ה-18 בכל חודש, ורק
אם תאריך העדכון של המשאב ב-CKAN השתנה מאז הטעינה האחרונה שהצליחה (‏`--force`
עוקף). אותו דפוס של [land-ownership.md](land-ownership.md):

1. הורדת ה-zip **דרך `data.gov.il` ולא `aws-e.data.gov.il`** - ‏`resource_show`
   מחזיר את השני, והוא ענה ל-GitHub ב-200 עם עמוד HTML (הטעינה הראשונה,
   22.10.2026). ‏`direct_url` מחליף את המארח. קריאה ב-pyshp, המרה ITM → WGS84 ב-pyproj עם **אותה מחרוזת
   `ITM_DEF`** של `_shared/geocode/itm.ts`.
2. רשומה פגומה (גוש או חלקה לא מספריים, חלקה 0) **נזרקת ונספרת**. מעל 1%
   נזרקות - הטעינה נכשלת.
3. כתיבה במנות של 5,000 תחת `batch` חדש.
4. ‏`parcels_open_finish` מוחקת את ה-batch הקודם **רק אם נכתבו לפחות מיליון
   חלקות**. הורדה שנקטעה לא מוחקת חצי מדינה; הנתונים הקודמים נשארים.

יומן: `parcels_open_loads`. הרצה ידנית: Actions → "שכבת החלקות הפתוחה" (עם
`dry_run` להורדה וניתוח בלי כתיבה).

```sh
python3 scripts/parcels_open_test.py                    # בדיקת הצמצום וההמרה, בלי רשת
python3 scripts/parcels_open_loader.py --file parcels.zip --dry-run
```

## מי קורא

| מה | |
| --- | --- |
| `parcel_open_of(gush, helka)` | חלקה אחת, ‏service_role בלבד |
| `address_parcel_from_deals(city, street, house_number)` | כתובת → הגוש והחלקה הנפוצים בעסקאות רשות המיסים שנרשמו בה. ‏62ms; ‏`city_id_for_name` נקראת פעם אחת ולא לכל עסקה (שם זה היה 37 שניות) |
| `planning_lookup` בבוט (‏`openParcelAnswer` ב-`agent.ts`) | כתובת מחוץ לעפולה שאינה במטמון של GovMap, וגוש/חלקה שאינם בקדסטר של עפולה: עונה `source: "parcels_open"`, ‏`partial: true` - גוש, חלקה, שטח, סטטוס, בעלות מהטאבו ומפה - ומפנה ב-`crm_planning_url` לייעוד ולתוכניות |

**הגבול של כתובת:** בלי שכבת כתובות פתוחה, כתובת מתורגמת לחלקה רק אם נרשמה
בה עסקה. כתובת בלי עסקה - עדיין `city_not_supported` עם הקישור.
