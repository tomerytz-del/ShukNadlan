# כפתור ליעד המדויק, בלי קישור ארוך

הודעה לסוכן/ת בוואטסאפ לא מדביקה כתובת של האזור האישי ולא שולחת ל-`/crm`
בלי יעד. הפעולה היא כפתור שפותח את המסך עצמו: כרטיס ליד, ביקוש פתוח,
עריכת נכס, סיור, הסכם, העלאת תמונות (כרטיס הנכס), או הרשימה המסוננת.

הנתיב נבנה פעם אחת ב-`notificationPath` / `reminderFindingPath` /
`screenBundle` ב-`supabase/functions/_shared/agent-deep-link.ts`.
`handleGotoParam` ב-`assets/crm.js` פותח אותו. `?goto=bell` פותח את הפעמון.

בחלון 24 השעות יוצאת **הודעה אחת** (לא שלוש):

- יעד אחד: `cta_url`.
- כמה יעדים: רשימה, כפתור "לאן לפתוח", עד 9 שורות, ואחרונה "הכול" לרשימה
  המסוננת. הלחיצה חוזרת כ-`nav:` + נתיב יחסי, והוובהוק שולח `cta_url` אחד.
  נתיב שאינו `/crm?goto=` מוכר או `/agent?slug=` נדחה.
- הגוף בלי `https://`. שורת ההפסקה בחלון היא "מסך התראות והודעות", בלי
  כתובת: ל-Meta יש כפתור קישור אחד, והוא היעד.

כפתור אינטראקטיבי שנדחה (לא 131050) נשלח שוב כטקסט **עם** הקישור, כדי
שההתראה לא תיפול. זו נפילה, לא הגוף הרגיל.

קישור שהסוכן/ת מעביר/ה ללקוח/ה (דף נכס, חתימה, מיניסייט) נשאר טקסט.
מייל נשאר עם קישור.

## תבנית UTILITY לאישור - לא הוגשה

לא להגדיר את הסוד ולא להגיש למטא לפני אישור. הקוד משתמש בה רק כשהסוד מוגדר,
ואחרת נשאר על התבנית המאושרת בייט של היום (כולל כפתור הכיבוי וכתובת ב-`{{2}}`).

| | התראות | תזכורות |
| --- | --- | --- |
| סוד השם | `WHATSAPP_NOTIFY_UTILITY_TEMPLATE` | `WHATSAPP_REMINDER_UTILITY_TEMPLATE` |
| סוד השפה | `WHATSAPP_NOTIFY_UTILITY_TEMPLATE_LANG` (ברירת מחדל `he`) | `WHATSAPP_REMINDER_UTILITY_TEMPLATE_LANG` |
| שם מוצע | `agent_alert_utility` | `agent_reminder_utility` |
| קטגוריה | UTILITY | UTILITY |
| שפה | he | he |

גוף:

```
שלום {{1}},
{{2}}

להפסקה: מסך התראות והודעות.
```

`{{1}}` השם הפרטי. `{{2}}` סיכום בשורה אחת, בלי כתובת, בלי שורה חדשה,
בלי ארבעה רווחים.

כפתור אחד, סוג URL:

- טקסט הכפתור: `פתיחה` (קבוע. בתבנית אי אפשר כותרת אחרת לכל סוג.)
- בסיס: `https://shuknadlan.co.il/`
- הסיומת הדינמית `{{1}}` היא הנתיב **בלי** לוכסן מוביל, למשל
  `crm?goto=accLeads&lead=<uuid>` או `crm?goto=accLeads` כשיש כמה לידים
  ("הכול").

כפתור הכיבוי של התבנית המאושרת היום לא עובר לכאן, כי לתבנית הזו כפתור URL
אחד והוא היעד. הדרך להפסיק כתובה בגוף, והמסך הוא התראות והודעות. אם מטא
תדחה UTILITY בלי כפתור הפסקה, לא מגדירים את הסוד.

דוגמה שהקוד שולח אחרי אישור, בלי להגיש אותה עכשיו:

```json
{
  "type": "template",
  "template": {
    "name": "agent_alert_utility",
    "language": { "code": "he" },
    "components": [
      { "type": "body", "parameters": [
        { "type": "text", "text": "דנה" },
        { "type": "text", "text": "ליד חם מדנה" }
      ]},
      { "type": "button", "sub_type": "url", "index": "0",
        "parameters": [{ "type": "text", "text": "crm?goto=accLeads&lead=UUID" }] }
    ]
  }
}
```

## מה לא השתנה

אין שליחה חדשה. דחיפה של כמה התראות היא עדיין הודעה אחת. לחיצה על רשימה
היא תשובה לבקשת הסוכן/ת, לא דחיפה. אין מיגרציה, אין פריסה, ואין הגשה למטא.
