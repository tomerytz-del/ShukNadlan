# מבזקי הנדל"ן — הרצועה בדף הבית

רצועת ה"מבזק" בדף הבית מתמלאת אוטומטית: מנוע שרץ ב-GitHub Actions אוסף
ידיעות מפרסומי עיריית עפולה ומאתרי החדשות והנדל"ן המובילים בארץ, מסנן את מה
שאינו נוגע לדיור, מנסח שורת מבזק ב-Claude ושומר ב-Supabase. הרצועה מציגה את
המבזקים ברוטציה, ולחיצה עליה פותחת את **עשרת האחרונים** ברשימה שאפשר לגלול בה.

לפני השינוי הזה הרצועה הציגה שתי כותרות קשיחות בקוד, והכפתור "כל העדכונים"
פתח `alert()` של דמו. `loadTicker()` אמנם הייתה כתובה, אבל היא לא נקראה
מעולם והטבלה שהיא ניסתה לקרוא (`news_items`) לא הייתה קיימת.

## הקבצים

| קובץ | תפקיד |
| --- | --- |

| `news_engine/relevance.py` | סינון מילות המפתח וקביעת ההיקף (עפולה / העמק / ארצי) |
| `news_engine/analyzer.py` | הפרומפט ל-Claude והפלט המובנה |
| `news_engine/models.py` | סכמת הפלט (Pydantic) ומוני ההרצה |

| `lead_engine/feeds.py` | *משותף* עם מנוע הלידים — הורדת פידים, ניקוי HTML, פתיחת עטיפות הפניה |

## הזרימה

1. **מקורות** — הפידים הפעילים מטבלת `news_sources` (ובנוסף `NEWS_FEED_URLS`
   אם הוגדר, ו-`--feed` בשורת הפקודה).
2. **קריאה** — כל פיד יורד ומפורסר. פיד שנשבר לא מפיל את ההרצה: הוא מסמן את
   עצמו ב-`last_error` בטבלת המקורות, וההרצה ממשיכה לפיד הבא.
3. **סינון גיל** — ידיעה ישנה מ-`NEWS_MAX_AGE_DAYS` (ברירת מחדל 21) יוצאת.
   "מבזק" הוא הבטחה, וכותרת בת חודשיים ברצועה שוברת אותה.
4. **סינון מילות מפתח** (`relevance.py`) — רץ **לפני** כל פנייה ל-API, ולכן
   ידיעה שאינה נדל"ן לא עולה כסף בכלל. ידיעה מקומית עוברת עם מילת נדל"ן אחת;
   ידיעה ארצית צריכה גם מילת שוק (ריבית, מחירי הדיור, מס רכישה וכו'), אחרת כל
   ידיעה שמזכירה "קבלן" הייתה נכנסת לרצועה.
5. **מניעת כפילויות** — בדיקת `source_url` מול Supabase, גם היא לפני Claude.
6. **ניסוח** — Claude מקבל את הידיעה ומחזיר אובייקט מובנה: שורת מבזק קצרה,
   תקציר של 1–2 משפטים, נושא, היקף וציון רלוונטיות.
7. **שמירה** — `news_items`. פריט שנדחה נשמר עם `status = 'rejected'` ולא
   נמחק, אחרת ההרצה הבאה הייתה מנתחת אותו שוב על חשבון התקציב.

## מסד הנתונים

המיגרציה `20260909090000_news_ticker.sql` יוצרת:

- **`news_sources`** — הפידים. נזרעת עם רשימת ברירת המחדל (למטה). מנוהלת
  בידי מנהל/ת הפלטפורמה בלבד, ואינה נקראת מהדפדפן כלל.
- **`news_items`** — המבזקים. `source_url` הוא UNIQUE — רשת הביטחון מפני
  כפילויות גם כששתי הרצות חופפות.
- **`news_items_public`** — ה-view שהאתר קורא: בלי `source_url` הגולמי ובלי
  שדות התחקור (`raw_content`, `analysis`, `model`). מוסיף `is_local` מחושב.

המיגרציה נכנסת אוטומטית עם המיזוג ל-`main` (ראו `docs/supabase-migrations.md`).

### מקורות ברירת המחדל

| מקור | היקף |
| --- | --- |
| עיריית עפולה — הודעות ופרסומים (`afula.muni.il/rss`) | עפולה |
| עיריית עפולה בחדשות — תכנון, בנייה ומכרזים | עפולה |
| נדל"ן בעפולה | עפולה |
| נדל"ן בעמק יזרעאל ובסביבה | אזור |
| נדל"ן ארצי — גלובס וכלכליסט | ארצי |
| נדל"ן ארצי — TheMarker, ynet וביזפורטל | ארצי |
| משכנתאות, ריבית ומדד מחירי הדיור | ארצי |
| גלובס — ערוץ נדל"ן (פיד ישיר) | ארצי |

רוב המקורות הם שאילתות `news.google.com/rss/search` ולא פידים ישירים של
האתרים, וזו החלטה מכוונת: פיד ישיר של אתר חדשות הוא החוליה היציבה פחות
בשרשרת — סעיף נסגר, מזהה מספרי משתנה, והמקור שותק בלי שאיש שם לב. שאילתת
גוגל עומדת בפני השינויים האלה, וה-`site:` שבתוכה מצמצם אותה לאתרים המובילים.
‏`canonical_url()` ב-`feeds.py` פותחת את עטיפת ההפניה של גוגל, כך שהקישור
שנשמר הוא של האתר עצמו.

### הוספה, כיבוי או החלפה של מקור

אין (עדיין) מסך ניהול למקורות המבזקים. ב-SQL Editor של Supabase:

```sql
-- הוספה
insert into public.news_sources (name, url, source_type, scope)
values ('שם המקור', 'https://…/rss.xml', 'news', 'afula');

-- כיבוי מקור שנשבר
update public.news_sources set active = false where name = 'שם המקור';

-- מה מצב המקורות? (עמודת last_error מגלה פיד שבור)
select name, active, last_status, last_error, items_seen, news_created, last_fetched_at
from public.news_sources order by created_at;
```

חלופה בלי לגעת בטבלה: משתנה הסביבה `NEWS_FEED_URLS` (כתובות מופרדות בפסיק),
שמוגדר כ-Repository Variable. הוא **נפרד** מ-`RSS_FEED_URLS` של מנוע הלידים.

## הרצה

```bash
python news_scraper.py                 # הרצה מלאה
python news_scraper.py --dry-run       # לנתח בלי לשמור ל-Supabase
python news_scraper.py --limit 5       # לכל היותר 5 ידיעות חדשות
python news_scraper.py --feed URL      # פיד יחיד, בלי טבלת המקורות
python news_scraper.py --no-claude     # סינון וניסוח היוריסטי בלבד (בחינם)
python news_scraper.py --verbose       # לוג מפורט
```

ב-GitHub Actions: לשונית Actions → "מנוע מבזקי נדל"ן" → Run workflow. שם יש
את אותם דגלים כשדות (`dry_run`, `no_claude`, `limit`).

בדיקת הסינון בלבד, בלי רשת ובלי מפתחות:

```bash
python scripts/news_filter_test.py
```

## משתני סביבה

המנוע חולק את הסודות של מנוע הלידים — אין צורך להגדיר חדשים.

| משתנה | חובה | ברירת מחדל |
| --- | --- | --- |
| `SUPABASE_URL` | כן | — |
| `SUPABASE_SERVICE_ROLE_KEY` | כן | — |
| `ANTHROPIC_API_KEY` | לא | בלעדיו רץ בניסוח היוריסטי |
| `CLAUDE_MODEL` | לא | `claude-sonnet-5` |
| `NEWS_FEED_URLS` | לא | ריק |
| `MAX_NEW_NEWS_PER_RUN` | לא | 25 |
| `MIN_NEWS_SCORE_TO_PUBLISH` | לא | 5 |
| `NEWS_MAX_AGE_DAYS` | לא | 21 |
| `NEWS_MAX_ENTRIES_PER_FEED` | לא | 30 |

> `SUPABASE_SERVICE_ROLE_KEY` עוקף RLS. הוא רץ אך ורק ב-GitHub Actions —
> אסור להטמיע אותו בדפדפן.

### הרצה בלי Claude

בשונה ממנוע הלידים, `ANTHROPIC_API_KEY` אינו חובה כאן. בלעדיו המנוע עדיין
אוסף ומסנן, ומנסח את המבזק היוריסטית: כותרת הפיד כמו שהיא (מקוצרת, בלי
חתימת האתר בסוף) ותחילת גוף הידיעה כתקציר. פחות מלוטש — אבל מבזק ריק גרוע
ממבזק פשוט. עם המפתח, Claude מנסח שורה שנקראת בהעברת עין אחת, מדייק את
ההיקף ומסנן תוכן שיווקי שהמילים לבדן לא תופסות.

## הצד של הגולש/ת

- הרצועה מתחילה לרוץ מיד עם מבזקי ברירת המחדל שבקוד, ומוחלפת במה שנאסף ברגע
  שהתשובה מ-Supabase חוזרת. אין רצועה ריקה בטעינה, ואין תלות ב-DB לתצוגה
  הראשונה.
- לחיצה על שורת המבזק **או** על "כל העדכונים ←" פותחת את רשימת עשרת
  האחרונים. הרשימה נגללת, וכל מבזק שיש לו קישור נפתח בלשונית חדשה.
- הרוטציה נעצרת בזמן שהרשימה פתוחה.
- `prefers-reduced-motion` מכבה את אנימציית ההחלפה ואת הנקודה המהבהבת.
- לצד המבזקים החיצוניים נכנסות לרצועה גם עסקאות שנסגרו בפלטפורמה עצמה
  (`market_deals`) — זה המבזק שאף אתר חדשות לא יכול לתת. שני המקורות
  מתמזגים לרשימה אחת ממוינת לפי זמן ונחתכים לעשרה.

## כוונון

- **יותר מדי רעש ברצועה** — העלו את `MIN_NEWS_SCORE_TO_PUBLISH` (למשל 7).
  ידיעה מקומית מקבלת ציון גבוה יותר מארצית מלכתחילה, ולכן הידוק הסף מקרב
  את הרצועה לעפולה.
- **מילה שחוזרת ולא נתפסת** — הוסיפו אותה ל-`REALTY_TERMS` או
  ל-`NATIONAL_MARKET_TERMS` ב-`news_engine/relevance.py`, והריצו
  `python scripts/news_filter_test.py`.
- **מבזק שגוי שכבר פורסם** — `update public.news_items set status = 'rejected'
  where id = '…';`. השורה נשארת, ולכן הידיעה לא תיאסף שוב.
