# דף הנחיתה למתווכים (`/for-brokers`)

דף סטטי שמסביר מה הפלטפורמה נותנת למשרד תיווך. הוא לא דף המתווכים של עיר:
‏`/brokers` ו-`brokers-page.ts` מגישים את `/{עיר}/מתווכים`, ואין לגעת בהם
בשביל הדף הזה.

| | |
| --- | --- |
| קובץ | `for-brokers.html` |
| כתובת | `https://shuknadlan.co.il/for-brokers` |
| הפניה | `/for-brokers.html` → `/for-brokers` ב-`_redirects` (`301!`) |
| הצטרפות | `/agency-signup` |
| מחירים | `/pricing` |

הנוסח הגלוי הוא הנוסח שאושר ב-6.11.2026. לא מנסחים אותו מחדש: בלי מקף ארוך,
בלי לוכסן מגדר, בלי שם או מספר רישיון של מפעיל האתר, ובלי ספירת נכסים,
מודעות או משרדים. מילת המפתח היא "מתווכים", ולכן `check_yoetz_copy.py`
מדלג על הקובץ ומתיר את עוגן "פלטפורמה למתווכים" (פוטר, `/agents`,
`/agencies`) ואת השורה ב-`llms.txt`. הכלל בשאר האתר לא השתנה.
‏`docs/yoetz-copy.md`.

הערות עריכה מתוך הטיוטה ("כפי שמופיע ב-`/pricing`", "כאן לא חוזרים על טבלת
המחירים") אינן מוצגות. הטענה עצמה מוצגת, ופירוט המכסות נשאר ב-`/pricing`.

הטבת "6 חודשי Elite במתנה", פסקת "הטבת השקה", והמשפט "בתקופת ההשקה לא
משלמים ולא נותנים כרטיס אשראי" מסומנים `hidden`. הם נראים רק כש-
`Tiers.PROMO.active` ב-`assets/tiers.js` דולק, כמו בדף המסלולים. הסקריפט
רץ ב-`<head>` לפני הציור, כדי שההצגה לא תזיז את הדף. בלי JS, או כשהדגל
כבוי, ההטבה נשארת מוסתרת. תיאור ה-meta, שאלת ההתחייבות ב-FAQ וה-JSON-LD
אינם מזכירים את המתנה, כדי שלא יישאר נוסח מיושן באינדקס.

## סכמה

שלושה בלוקי JSON-LD ב-`<head>`, זהים לטקסט הגלוי:

| סוג | מה |
| --- | --- |
| `SoftwareApplication` | שם, `BusinessApplication`, `Web`, `he`, `areaServed` ישראל (`Country` / `Israel`). `offers` הוא `Offer` עם `url` אל `/pricing`, בלי מחיר |
| `FAQPage` | שש השאלות שב-`<details>`, מילה במילה |
| `BreadcrumbList` | דף הבית → למתווכים |

תמונת השיתוף היא `assets/og-default.png` (1200×630), כמו בשאר הדפים הסטטיים.
הלוגו בכותרת ובפוטר נושא `width` ו-`height`.

## קישורים

הפוטר המשותף (עמודת "שוק נדל״ן", בכל דף ציבורי כולל `market-soon.html`) מקבל
"פלטפורמה למתווכים". עוד הפניות: שורה ב-`/agents` וב-`/agencies`, "מה כוללת
הפלטפורמה" בניווט של `/pricing`, ו"למי זה מתאים ומה מקבלים" ב-`/agency-signup`.
