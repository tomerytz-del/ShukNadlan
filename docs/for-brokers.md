# דף הנחיתה למתווכים (`/for-brokers`)

דף סטטי שמסביר מה הפלטפורמה נותנת למשרד תיווך. הוא לא דף המתווכים של עיר:
‏`/brokers` ו-`brokers-page.ts` מגישים את `/{עיר}/מתווכים`, ואין לגעת בהם
בשביל הדף הזה.

| | |
| --- | --- |
| קובץ | `for-brokers.html` |
| כתובת | `https://shuknadlan.co.il/for-brokers` |
| הפניה | `/for-brokers.html` → `/for-brokers` ב-`_redirects` (`301!`) |
| הצטרפות | `/agency-signup` |
| מחירים | `/pricing` |

הנוסח הגלוי הוא הנוסח שאושר ב-6.11.2026. לא מנסחים אותו מחדש: בלי מקף ארוך,
בלי לוכסן מגדר, בלי שם או מספר רישיון של מפעיל האתר, ובלי ספירת נכסים,
מודעות או משרדים. מילת המפתח היא "מתווכים", ולכן `check_yoetz_copy.py`
מדלג על הקובץ ומתיר את עוגן "פלטפורמה למתווכים" (פוטר, `/agents`,
`/agencies`) ואת השורה ב-`llms.txt`. הכלל בשאר האתר לא השתנה.
‏`docs/yoetz-copy.md`.

הערות עריכה מתוך הטיוטה ("כפי שמופיע ב-`/pricing`", "כאן לא חוזרים על טבלת
המחירים") אינן מוצגות. הטענה עצמה מוצגת, ופירוט המכסות נשאר ב-`/pricing`.

הטבת "חודשיים Elite במתנה", פסקת "הטבת השקה", והמשפט "בתקופת ההשקה לא
משלמים ולא נותנים כרטיס אשראי" מסומנים `hidden`. הם נראים רק כש-
`Tiers.PROMO.active` ב-`assets/tiers.js` דולק, כמו בדף המסלולים. הסקריפט
ב-`<head>` קובע את הדגל, ומיד אחרי האלמנטים מסיר את `hidden` (בלי לדרוס
אותו ב-CSS), לפני שהם נצבעים. בלי JS, או כשהדגל כבוי, ההטבה נשארת מוסתרת. תיאור ה-meta, שאלת ההתחייבות ב-FAQ וה-JSON-LD
אינם מזכירים את המתנה, כדי שלא יישאר נוסח מיושן באינדקס.

## סכמה

שלושה בלוקי JSON-LD ב-`<head>`, זהים לטקסט הגלוי:

| סוג | מה |
| --- | --- |
| `SoftwareApplication` | שם, `BusinessApplication`, `Web`, `he`, `areaServed` ישראל (`Country` / `Israel`). `offers` הוא `Offer` עם `url` אל `/pricing`, בלי מחיר |
| `FAQPage` | שש השאלות שב-`<details>`, מילה במילה |
| `BreadcrumbList` | דף הבית → למתווכים |

תמונת השיתוף היא `assets/og-default.png` (1200×630), כמו בשאר הדפים הסטטיים.
הלוגו בכותרת ובפוטר נושא `width` ו-`height`.

## קישורים

הפוטר המשותף (עמודת "שוק נדל״ן", בכל דף ציבורי כולל `market-soon.html`) מקבל
"פלטפורמה למתווכים". עוד הפניות: שורה ב-`/agents` וב-`/agencies`, "מה כוללת
הפלטפורמה" בניווט של `/pricing`, ו"למי זה מתאים ומה מקבלים" ב-`/agency-signup`.

## החלק העליון: דף נחיתה לסוכנים חדשים (17.11.2026)

מעל הנוסח המאושר יושב עכשיו `div.lp`: hero עם הכותרת "מצטרפים לקהילה החכמה
של יועצי הנדל״ן של ישראל" והסלוגן "מתחברים ▪ משתפים ▪ סוגרים עסקאות", שלושה
צעדים, כרטיסי גבריאלה והמנטור, ופס לבעלי משרדים. עוצב בקנבס של קלוד דיזיין
(קרם, ירוק וטרקוטה, שפה אחרת מהאתר), ולכן כל כלל ה-CSS שלו נושא `html body .lp`.

- **כל כפתורי ההצטרפות בחלק הזה מובילים ל-`/pricing`**, לא ישר ל-`/agency-signup`:
  הדף הוא ההיכרות, ובחירת המסלול והרשמה קורות בדף המחירים. הסגירה שבתוך
  `main.doc` נשארה כמו שהייתה (קישור ישיר להרשמה).
- **ה-H1 נשאר "פלטפורמת מרקטפלייס נדל״ן ו-CRM למתווכים בישראל"**, בשביל
  החשיפה בחיפושי מתווכים בגוגל (החלטת בעל האתר, 17.11.2026). הוא מוצג כתגית
  קטנה מעל הכותרת הגדולה, "מצטרפים לקהילה החכמה של יועצי הנדל״ן של ישראל",
  שהיא `<p class="lp-display">` ולא כותרת. **אין להפוך אותה ל-H1.** שורת
  ה-deck המאושרת חזרה כמו שהייתה.
- **הטבת החודשיים** (`.lp-promo`) נושאת `promo-gift` ו-`hidden`, ו-`revealPromoGifts()`
  נקראת מיד אחרי ה-hero, כמו בשאר הדף.
- **בלי מחירים ובלי ספירות**, כמו שאר הדף: הפירוט ב-`/pricing`.
- התמונות: `gabriela-pop` (ה-hero), `gabriela-pose-f` והמנטור (`mentor-cutout`),
  כולן עם `width` ו-`height`. אותן שלוש תנוחות של גבריאלה כמו ב-`/pricing`.

**ה-CSS של `.lp` יושב ב-`<style id="lp-css">` נפרד**, אחרי ה-`<style>` הראשון.
`scripts/build_join_pages.py` מעתיק לארבעת דפי ה-join את ה-`<style>` הראשון בלבד,
ו-`join_pages.yml --check` נכשל אם הדפים אינם מה שהמחולל מייצר. כלל חדש לחלק
העליון נכנס לבלוק הנפרד, לא לראשון; ושינוי בראשון מחייב `python scripts/build_join_pages.py`.

**הפרסום לרשתות (עודכן 18.11.2026):** הנוסח בדף ובשאלות הנפוצות אומר שנכס עולה
לדפי הפייסבוק ולאינסטגרם של שוק הנדל״ן **ולקבוצות האזוריות הרלוונטיות בכל עיר**
(החלטת בעל האתר). בפועל הפרסום האורגני עובר מ-27.10.2026 רק דרך מנהל המדיות
החיצוני (`docs/facebook-auto-publish.md`), ולכן אין לכתוב בדף מועד או מנגנון
פרסום. הטקסט ב-FAQ וב-JSON-LD נשאר זהה מילה במילה, וכך גם בשתי הפסקאות בראש הדף
וב-`meta description`.
