# "יועצי נדל״ן" ולא "מתווכים" (החלטת תומר, 27.10.2026)

בכל טקסט שהאתר מציג - ניווט, כותרות, כפתורים, טפסים, תגיות SEO ו-JSON-LD, ודפי
הסוכנים (CRM) - **"יועץ/יועצי נדל״ן"** במקום "מתווך/מתווכים". באתר החי, לא מאחורי
הדגל. תמיד גרשיים אמיתיים (‏`״`).

## כללי ההחלפה

| ישן | חדש |
| --- | --- |
| מתווך | יועץ נדל״ן |
| המתווך / המתווך/ת | יועץ הנדל״ן |
| מתווכים / המתווכים | יועצי נדל״ן / יועצי הנדל״ן |
| מתווכי X | יועצי הנדל״ן של X |
| פעלים ותארים עם ‎/ת‎ סביב המילה | רבים ניטרלי (יחזרו, מומלצים, מהאזור) |
| בלי מתווך (פרויקטים) | בלי תיווך |

## מה נשאר

- שמות בחוק: רשם המתווכים, פנקס המתווכים, חוק המתווכים, תקנות המתווכים, מאגר המתווכים (של משרד המשפטים) - ונוסח החוק
  ב-CRM ("פרטי המתווך" על טופס הזמנת שירותי תיווך).
- מסמכים משפטיים (‏`terms.html`, ‏`privacy.html`, ‏`ethics-code.html`) ותבניות ההסכם - רק
  אחרי בדיקה משפטית.
- "רישיון תיווך", "דמי תיווך", "משרד תיווך" - המונח הוא הפעולה או המשרד, לא האדם.
- כתובות ‏`/{עיר}/מתווכים` (נתיבי SEO של PR #955) - רק טקסט העוגן משתנה.
- **חריג אחד בעוגן:** בבלוק "חיפושים פופולריים" בפוטר הקישור ל-‏`/afula/מתווכים` כתוב "מתווכים בעפולה" (תומר 29.10 01:40, גבריאלה אישרה - הביטוי שמחפשים בגוגל). שאר הקישורים לדף הזה, בגוף הדפים, נשארים "יועצי נדל״ן בעפולה". ‏`check_yoetz_copy.py` מתיר בדיוק את העוגן הזה.
- דפי המתווכים (‏`/agencies`, ‏`/agents`; החלטה 10, אושרה במלואה 27.10): ב-`<title>`, ב-`meta
  description`, ב-`og:title` וב-`og:description` הניסוח המשולב "יועצי נדל״ן ומתווכים", וב-`/agencies`
  משפט גלוי אחד: "יועצי נדל״ן (מתווכים) בעפולה ובעמק". ה-H1 והכפתורים - "יועצי נדל״ן".
  כותרת `/agencies` (1.11.2026) היא "משרדי תיווך ומתווכים בעפולה והעמק | שוק נדל״ן",
  כדי להבדיל אותה מ-`/agents`.
- הקטגוריה במסד "בלוג המתווכים" - מוצגת כ"הבלוג של יועצי הנדל״ן" (המיפוי בקוד).
- קבצי PR #955 (‏`brokers*`, ‏`silo*`) - PR המשך אחרי המיזוג. גם טקסטי הבוטים והמיילים
  ב-`supabase/functions` (לא מוגשים מהאתר) ותוכן כתבות במסד.
